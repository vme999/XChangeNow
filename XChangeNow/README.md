# XChangeNow

一个简单易用的货币汇率转换应用。

## 功能特点

- 实时汇率查询
- 支持多种货币
- 历史记录保存
- 深色模式支持
- 离线缓存

## 环境要求

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## 安装说明

1. 克隆项目
2. 在 `Config/APIConfig.swift` 中配置您的 API key
3. 运行项目

## API 密钥

本项目使用 Exchange Rate API。您需要：
1. 访问 https://www.exchangerate-api.com/
2. 注册并获取 API key
3. 在配置文件中替换 API key
